# Media

Simulator flight recordings from the qualification campaign, captured with
Windows Game Bar (`Win+Alt+R`).

| file | what it shows |
|---|---|
| `gate2_pass.gif` | 11 s excerpt of `gate2_pass.mp4`, embedded at the top of the main README (640×360, 10 fps) |
| `gate2_pass.mp4` | Run `flit56`, 2026-07-30 — start countdown, Gate 1, Gate 2, and the bank onto the Gate-3 leg. The deepest result the controller achieved, and the source of the GIF. |
| `vq1_good_start.mp4` | 2026-06-28 — an earlier clean launch and opening leg, from the era before the Gate-3 work began. |

Both clips are cropped to the simulator's 1280×720 viewport (the raw captures
were 2880×1920, roughly three-quarters empty desktop) and re-encoded to keep the
repository small. They are otherwise unedited: no cuts, no speed changes.

`gate2_pass.mp4` is trimmed to the first 20 seconds. The remainder of the raw
capture is pause-menu navigation, not flight.

Note: simulator access ended at the qualification deadline (2026-08-03), so no
new footage can be recorded. What is here is what exists.
